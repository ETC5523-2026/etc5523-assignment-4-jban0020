# Launch the Backyard Ultra Shiny App

Launches an interactive Shiny dashboard for exploring stopped-runner
performance at the 2026 Backyard Ultra World Team Championships.

## Usage

``` r
run_wtc_app()
```

## Value

Launches the Shiny application in a web browser.

## Details

The application allows users to compare nations and competition classes,
apply performance filters and explore summary statistics.

## Examples

``` r
if (FALSE) { # \dontrun{
run_wtc_app()
} # }
```
